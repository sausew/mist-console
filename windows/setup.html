Welcome to MIST Console

A couple of steps and you'll be chatting. This wizard checks each piece and fixes what it can.

checking… Claude Code

The Console runs the official claude command-line app under the hood. Your Claude subscription signs in through it; no API key is needed.

checking… Git for Windows

Claude Code uses Git Bash to run commands. If it's missing, grab it from git-scm.com/download/win (default options are fine), then come back; this page rechecks on its own.

checking… Sign in

Sign in with your Claude account. A browser window will open; approve it and return here.

Summon her from anywhere

      
While the Console is running, press Ctrl+Alt+Space in any app and a quick-entry box appears at the bottom of the screen. Type a thought, hit Enter, and the Console opens on that chat; Esc dismisses it.
